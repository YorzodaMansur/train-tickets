
КОРИ ЛАБОРАТОРИИ №12

Мавзуъ: BACKEND (1) — Composer, Front Controller, Router ва View

Лоиҳа: Системаи фурӯши онлайнии чиптаҳои қатораҳои байнишаҳрӣ

============================================================
1. МАҚСАДИ КОРИ ЛАБОРАТОРӢ
============================================================

Мақсади кори лаборатории №12 омӯзиш ва татбиқи сохтори
асосии Backend дар лоиҳаи вебӣ мебошад.

Дар ин лаборатория технологияҳо ва усулҳои зерин истифода
мешаванд:

1. Composer — идоракунии вобастагиҳои PHP ва боркунии
   автоматии синфҳо.
2. PSR-4 — стандарти ҷойгиршавӣ ва боркунии синфҳо.
3. Front Controller — нуқтаи ягонаи воридшавии дархостҳо.
4. Router — муайян кардани масири мувофиқи дархости корбар.
5. Controller — коркарди мантиқи барнома.
6. View — намоиши маълумот ба корбар.
7. Layout — қолаби умумии саҳифаҳо.
8. Partial — қисмҳои такроран истифодашавандаи интерфейс.
9. HTTP Status Code — рамзҳои ҷавоби сервер.

Дар натиҷаи иҷрои лаборатория сохтори Backend-и лоиҳа
ташкил карда шуда, масирҳои асосӣ ва саҳифаҳои вебӣ
санҷида мешаванд.

============================================================
2. СОХТОРИ МАСИРҲОИ СИСТЕМА
============================================================

Дар лоиҳаи фурӯши онлайнии чиптаҳои қатора масирҳо барои
гузариш байни саҳифаҳои гуногуни система истифода мешаванд.

Ҳар як масир дар Router муайян карда мешавад ва дархости
корбар ба Controller-и мувофиқ равона мегардад.

2.1. Рӯйхати масирҳои GET

GET /                  - Саҳифаи асосӣ
GET /trips             - Рӯйхати сафарҳои қатора
GET /trips/{id}        - Маълумоти муфассали як сафар
GET /stations          - Рӯйхати истгоҳҳои роҳи оҳан
GET /login             - Саҳифаи воридшавӣ ба система
GET /register          - Саҳифаи бақайдгирии корбар

2.2. Шарҳи вазифаи ҳар як масир

1. GET /

Ин масир саҳифаи асосии системаро мекушояд.
Дар он номи система, маълумоти мухтасар, имконияти
ҷустуҷӯи сафар ва рӯйхати баъзе сафарҳо нишон дода мешавад.

Controller: HomeController
Метод: index()

2. GET /trips

Ин масир рӯйхати сафарҳои дастрасро нишон медиҳад.
Маълумот метавонад рақами қатора, истгоҳи рафтан,
истгоҳи омадан, вақти ҳаракат ва нархи чиптаро дар бар гирад.

Controller: TripController
Метод: index()

3. GET /trips/{id}

Ин масир барои дидани маълумоти муфассали як сафар
истифода мешавад.

Параметри {id} рақами мушаххаси сафар мебошад.
Масалан, /trips/1 маълумоти сафари дорои ID = 1-ро нишон медиҳад.

Controller: TripController
Метод: show($id)

Агар сафар бо чунин ID вуҷуд надошта бошад, сервер
ҷавоби 404 бармегардонад.

4. GET /stations

Ин масир рӯйхати истгоҳҳои роҳи оҳанро нишон медиҳад.
Масалан:
- Душанбе
- Хуҷанд
- Бохтар

Controller: StationController
Метод: index()

5. GET /login

Ин масир саҳифаи воридшавии корбарро мекушояд.
Дар он майдонҳои ворид кардани почтаи электронӣ ва
рамз ҷойгир карда мешаванд.

Controller: AuthController
Метод: login()

6. GET /register

Ин масир саҳифаи бақайдгирии корбари навро мекушояд.
Дар он майдонҳои ворид кардани ном, почтаи электронӣ
ва рамз ҷойгир карда мешаванд.

Controller: AuthController
Метод: register()

============================================================
3. ТАРТИБИ ОҒОЗ КАРДАНИ СЕРВЕР
============================================================

Барои санҷидани масирҳо аввал сервери дохилии PHP-ро
оғоз кардан лозим аст.

Қадамҳои иҷро:

1. Лоиҳаи train-tickets-ро дар Visual Studio Code кушоем.
2. Терминали PowerShell-ро кушоем.
3. Ба папкаи асосии лоиҳа мегузарем.
4. Фармони зеринро иҷро мекунем:

cd C:\Users\user\Desktop\train-tickets

5. Баъд сервери PHP-ро оғоз мекунем:

php -S localhost:8000 -t public

Агар сервер дуруст оғоз шавад, дар терминал паёми
оғози сервер нишон дода мешавад.

Масалан:

PHP Development Server started

Пас аз оғоз кардани сервер саҳифаи асосиро бо суроғаи
зерин мекушоем:

http://localhost:8000/

ЭЗОҲ:
Терминале, ки сервер дар он оғоз шудааст, бояд кушода
монад. Барои қатъ кардани сервер тугмаҳои Ctrl + C
истифода мешаванд.

============================================================
4. САНҶИШИ МАСИРҲОИ GET
============================================================

Барои санҷиши кори масирҳо фармони curl.exe истифода
мешавад. Ин фармон ба сервер дархости HTTP мефиристад
ва ҷавоби серверро нишон медиҳад.

4.1. Санҷиши саҳифаи асосӣ

Фармон:

curl.exe -i http://localhost:8000/

Натиҷаи интизоршаванда:

HTTP/1.1 200 OK

Шарҳ:
Рамзи 200 нишон медиҳад, ки сервер дархостро бомуваффақият
қабул ва коркард кардааст.

4.2. Санҷиши рӯйхати сафарҳо

Фармон:

curl.exe -i http://localhost:8000/trips

Натиҷаи интизоршаванда:

HTTP/1.1 200 OK

Шарҳ:
Ин масир рӯйхати сафарҳои қатораро нишон медиҳад.

4.3. Санҷиши маълумоти як сафар

Фармон:

curl.exe -i http://localhost:8000/trips/1

Натиҷаи интизоршаванда:

HTTP/1.1 200 OK

Шарҳ:
Дар ин ҳолат Router параметри ID-ро аз суроға гирифта,
онро ба методи show() дар TripController мефиристад.
Агар сафар бо ID = 1 мавҷуд бошад, маълумоти он намоиш дода мешавад.

4.4. Санҷиши рӯйхати истгоҳҳо

Фармон:

curl.exe -i http://localhost:8000/stations

Натиҷаи интизоршаванда:

HTTP/1.1 200 OK

Шарҳ:
Ин масир маълумоти истгоҳҳои роҳи оҳанро намоиш медиҳад.

4.5. Санҷиши саҳифаи воридшавӣ

Фармон:

curl.exe -i http://localhost:8000/login

Натиҷаи интизоршаванда:

HTTP/1.1 200 OK

Шарҳ:
Саҳифаи воридшавӣ кушода мешавад ва корбар метавонад
майдонҳои ворид кардани маълумоти худро бинад.

4.6. Санҷиши саҳифаи бақайдгирӣ

Фармон:

curl.exe -i http://localhost:8000/register

Натиҷаи интизоршаванда:

HTTP/1.1 200 OK

Шарҳ:
Саҳифаи бақайдгирии корбари нав намоиш дода мешавад.

============================================================
5. САНҶИШИ ХАТОИ 404 — NOT FOUND
============================================================

Рамзи HTTP 404 маънои онро дорад, ки саҳифа ё манбаи
дархостшуда дар система ёфт нашуд.

Дар лоиҳа ду ҳолати асосии санҷиши 404 мавҷуд аст.

5.1. Санҷиши масири номуайян

Фармон:

curl.exe -i http://localhost:8000/not-found

Натиҷаи интизоршаванда:

HTTP/1.1 404 Not Found

Шарҳ:
Масири /not-found дар Router муайян нашудааст.
Аз ин сабаб система саҳифаи хатои 404-ро нишон медиҳад.

5.2. Санҷиши ID-и мавҷуднабуда

Фармон:

curl.exe -i http://localhost:8000/trips/999

Натиҷаи интизоршаванда:

HTTP/1.1 404 Not Found

Шарҳ:
Масири /trips/{id} вуҷуд дорад, аммо сафар бо ID = 999
дар рӯйхати маълумотҳо мавҷуд нест.
TripController мавҷуд набудани сафарро муайян карда,
рамзи 404-ро бармегардонад.

5.3. Сабаби истифодаи 404

Истифодаи рамзи 404 ба корбар ва браузер имкон медиҳад,
ки фаҳманд, манбаи дархостшуда вуҷуд надорад.

Дар лоиҳа барои ин ҳолат шаблони умумии хатогиҳо
истифода мешавад:

views/errors/error.php

============================================================
6. САНҶИШИ ХАТОИ 405 — METHOD NOT ALLOWED
============================================================

Рамзи HTTP 405 маънои онро дорад, ки усули HTTP-и
истифодашуда барои масири муайян иҷозат дода нашудааст.

Масалан, агар масири /trips танҳо барои GET муайян шуда
бошад, дархости POST ба он иҷозат дода намешавад.

Фармон:

curl.exe -i -X POST http://localhost:8000/trips

Натиҷаи интизоршаванда:

HTTP/1.1 405 Method Not Allowed

Шарҳ:
Масири /trips вуҷуд дорад, аммо барои он усули POST
муайян карда нашудааст. Аз ин сабаб Router ҷавоби
405 бармегардонад.

Фарқи 404 ва 405:

404 — масири дархостшуда вуҷуд надорад.

405 — масир вуҷуд дорад, аммо усули HTTP-и истифодашуда
барои он иҷозат дода нашудааст.

============================================================
7. СОХТОРИ FRONT CONTROLLER ВА ROUTER
============================================================

Дар лоиҳа файли public/index.php ҳамчун Front Controller
истифода мешавад.

Front Controller нуқтаи ягонаи воридшавии дархостҳои
корбар ба барнома мебошад.

Вазифаҳои асосии он:

1. Бор кардани Composer Autoload.
2. Омода кардани функсияҳои умумӣ.
3. Эҷод кардани объекти Router.
4. Сабти масирҳои система.
5. Фиристодани дархост ба Router.
6. Иҷро кардани Controller-и мувофиқ.

Router вазифаи муайян кардани масири мувофиқро иҷро мекунад.

Масалан:

GET /trips

ба TripController ва методи index() равона мешавад.

GET /trips/1

ба TripController ва методи show(1) равона мешавад.

8. СОХТОРИ VIEW ВА ШАБЛОНҲО
============================================================

Барои ҷудо кардани мантиқи барнома аз намуди зоҳирӣ
сохтори View истифода мешавад.

Файли асосии View:

src/Core/View.php

Ин синф вазифаи кушодани шаблон ва пайваст кардани онро
бо Layout иҷро мекунад.

Layout қолаби умумии саҳифаҳо мебошад.
Дар он қисмҳои умумии интерфейс ҷойгир мешаванд:

- Header ва менюи навигатсионӣ;
- Қисми асосии саҳифа;
- Footer;
- Файлҳои CSS ва JavaScript.

Файли Layout:

views/layout.php

Partial файлҳои қисмҳои такроран истифодашавандаи
интерфейс мебошанд.

Масалан:

views/partials/nav.php
views/partials/footer.php

Шаблонҳои асосии лоиҳа:

views/home/index.php
views/trips/index.php
views/trips/show.php
views/stations/index.php
views/auth/login.php
views/auth/register.php
views/errors/error.php

Афзалияти чунин сохтор дар он аст, ки намуди зоҳирӣ
ва мантиқи коркарди маълумот аз ҳам ҷудо мешаванд.

9. БЕХАТАРИИ НАМОИШИ МАЪЛУМОТ
============================================================

Барои пешгирӣ кардани ҳамлаҳои XSS ҳангоми намоиш
додани маълумоти динамикӣ функсияи e() истифода мешавад.

Намуна:

<?= e($trip['train_number']) ?>

Ин функсия аломатҳои махсуси HTML-ро бехатар мегардонад.

Барои сохтани суроғаҳои саҳифаҳо функсияи url()
истифода мешавад.

Намуна:

<a href="<?= e(url('trips')) ?>">Сафарҳо</a>

Ин усул барои нигоҳ доштани бехатарӣ ва дурустии
суроғаҳои дохилии система муҳим мебошад.

============================================================
11. ХУЛОСА
============================================================

Дар натиҷаи иҷрои кори лаборатории №12 сохтори асосии
қисми Backend-и лоиҳаи «Системаи фурӯши онлайнии
чиптаҳои қатораҳои байнишаҳрӣ» омода карда мешавад.

Дар ҷараёни иҷрои кор истифодаи Composer ва стандарти
PSR-4 барои боркунии автоматии синфҳо омӯхта мешавад.

Бо истифода аз Front Controller дархостҳои корбар ба
як нуқтаи ягона ворид мешаванд. Router масири мувофиқро
муайян намуда, дархостро ба Controller равона мекунад.

Бо истифода аз View ва Layout намоиши маълумот аз
мантиқи барнома ҷудо карда мешавад. Partial имкон медиҳад,
ки қисмҳои такрории интерфейс дар чанд саҳифа истифода шаванд.

Ҳамчунин, кори масирҳои GET, параметри динамикии {id},
хатогиҳои 404 ва 405 ва функсияҳои e() ва url() омӯхта
ва санҷида мешаванд.

Ин сохтор барои васеъ кардани лоиҳа, пайваст кардани
пойгоҳи додаҳо, иҷрои амалиёти CRUD ва илова кардани
имкониятҳои нави система заминаи зарурӣ фароҳам меорад.
