# **3. Тартиби иҷрои санҷишҳо**

## **3.1. Санҷиши пайвастшавӣ ба пойгоҳи додаҳо тавассути PDO**

**Мақсад:** Санҷидани дурустии пайвастшавии веб-барнома ба пойгоҳи додаҳои MySQL/MariaDB бо истифодаи технологияи PDO (PHP Data Objects).

PDO интерфейси стандартии PHP барои кор бо пойгоҳи додаҳо мебошад. Он имкон медиҳад, ки дархостҳои SQL бехатар иҷро гардида, маълумот аз ҷадвалҳо гирифта, илова, таҳрир ва нест карда шавад.

**Тартиби иҷро:**

1. Барномаи XAMPP-ро кушода, серверҳои Apache ва MySQL-ро фаъол мекунем.
2. Дар VS Code папкаи лоиҳаи `train-tickets`-ро мекушоем.
3. Файли танзимоти пойгоҳи додаҳо `config/config.php`-ро месанҷем.
4. Боварӣ ҳосил мекунем, ки номи база `railway_tickets`, номи корбар `root`, рамз ва порти MySQL дуруст нишон дода шудаанд.
5. Файли `src/Core/Database.php`-ро мекушоем ва дурустии сохтани объекти PDO-ро месанҷем.
6. Веб-барномаро оғоз намуда, ба саҳифаи рейсҳо мегузарем.
7. Агар маълумот аз ҷадвалҳои пойгоҳи додаҳо гирифта шуда, саҳифа бе хатои пайвастшавӣ кушода шавад, пайвастшавии PDO дуруст кор мекунад.

Мисоли сохтани пайвастшавӣ:

```
$dsn = "mysql:host={$host};port={$port};dbname={$database};charset=utf8mb4";

$pdo = new PDO(
    $dsn,
    $username,
    $password,
    [
        PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION,
        PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC,
        PDO::ATTR_EMULATE_PREPARES => false
    ]
);
```

**Натиҷаи интизоршаванда:**

- Пайвастшавӣ ба база бомуваффақият иҷро мешавад.
- Маълумоти рейсҳо аз ҷадвали `trips` гирифта мешавад.
- Ҳангоми набудани база ё нодуруст будани танзимот хатои пайвастшавӣ ошкор мегардад.
- Маълумоти техникӣ ба корбари одӣ нишон дода намешавад.



Меъёри муваффақият

&#x20;Саҳифаи рейсҳо маълумотро аз база намоиш медиҳад.



## **3.2. Санҷиши амалиётҳои CRUD**

**Мақсад:** Санҷидани имкониятҳои асосии идоракунии маълумот дар ҷадвали `trips`.

CRUD аз чор амалиёти асосӣ иборат аст:

- Create — илова кардани маълумоти нав.
- Read — хондан ва намоиш додани маълумот.
- Update — тағйир додани маълумоти мавҷуда.
- Delete — нест кардани маълумот.

Дар лоиҳаи мо объекти асосии санҷиш рейси қатора мебошад.

### **3.2.1. Санҷиши Create — илова кардани рейси нав**

**Тартиби иҷро:**

1. Саҳифаи идоракунии рейсҳоро мекушоем.
2. Тугмаи «Илова кардани рейс»-ро пахш мекунем.
3. Дар форма маълумоти зеринро ворид мекунем:
   - Қатор — қатори мавҷуда, масалан, рақами `001`.
   - Хатсайр — Душанбе — Хуҷанд.
   - Сана ва вақти рафтан — 2026-12-15 08:00.
   - Сана ва вақти расидан — 2026-12-15 14:00.
   - Ҳолати рейс — `scheduled`.
   - Нархи чипта — `180.00`.
4. Маълумоти воридшударо санҷида, тугмаи «Захира кардан»-ро пахш мекунем.
5. Барнома маълумотро тавассути Controller ба Repository мефиристад.
6. Repository дархости SQL-ро тавассути PDO иҷро намуда, маълумотро ба ҷадвали `trips` илова мекунад.
7. Пас аз муваффақият корбар ба рӯйхати рейсҳо бармегардад.

Мисоли дархости SQL:

```
INSERT INTO trips (
    train_id,
    route_id,
    departure_time,
    arrival_time,
    status,
    base_price
)
VALUES (
    1,
    1,
    '2026-12-15 08:00:00',
    '2026-12-15 14:00:00',
    'scheduled',
    180.00
);
```

**Натиҷаи интизоршаванда:** Рейси нав ба пойгоҳи додаҳо илова шуда, дар рӯйхати рейсҳо намоиш дода мешавад.

### **3.2.2. Санҷиши Read — хондани маълумот**

**Тартиби иҷро:**

1. Ба саҳифаи рӯйхати рейсҳо мегузарем.
2. Барнома аз ҷадвали `trips` маълумотро мехонад.
3. Маълумот дар шакли ҷадвал намоиш дода мешавад.
4. Рақами қатор, номи хатсайр, вақти рафтан, вақти расидан, ҳолат ва нархи чипта санҷида мешаванд.

Намунаи маълумоти намоишшаванда:

| Қатор | Хатсайр          | Рафтан | Расидан | Нарх       |
| ----- | ---------------- | ------ | ------- | ---------- |
| 001   | Душанбе — Хуҷанд | 08:00  | 14:00   | 180 сомонӣ |
| 002   | Хуҷанд — Душанбе | 09:00  | 15:00   | 180 сомонӣ |

**Натиҷаи интизоршаванда:** Маълумоти сабтшуда дуруст ва пурра намоиш дода мешавад. Агар ягон рейс мавҷуд набошад, паёми мувофиқ нишон дода мешавад.

### **3.2.3. Санҷиши Update — таҳрир кардани маълумот**

**Тартиби иҷро:**

1. Дар рӯйхати рейсҳо рейси санҷиширо интихоб мекунем.
2. Тугмаи «Таҳрир»-ро пахш мекунем.
3. Маълумоти пештар сабтшуда дар форма нишон дода мешавад.
4. Нархи чиптаро аз `180.00` ба `200.00` тағйир медиҳем.
5. Маълумоти навро захира мекунем.
6. Рӯйхати рейсҳоро аз нав мекушоем ва тағйиротро месанҷем.

Мисоли дархости SQL:

```
UPDATE trips
SET base_price = 200.00
WHERE id = 1;
```

**Натиҷаи интизоршаванда:** Нархи рейс тағйир ёфта, қимати нав дар рӯйхати рейсҳо намоиш дода мешавад. Маълумоти дигари рейс бояд бетағйир монад.

### **3.2.4. Санҷиши Delete — нест кардани маълумот**

**Тартиби иҷро:**

1. Рейси махсус барои санҷиш сохташударо интихоб мекунем.
2. Тугмаи «Нест кардан»-ро пахш мекунем.
3. Агар система тасдиқи амалиётро талаб кунад, нест кардани рейсро тасдиқ мекунем.
4. Дархост тавассути усули POST фиристода мешавад.
5. Сервер дурустии CSRF token ва мавҷудияти рейсро месанҷад.
6. Агар рейс маҳдудияти калиди хориҷӣ надошта бошад, он нест карда мешавад.
7. Рӯйхати рейсҳоро аз нав мекушоем.

Мисоли дархости SQL:

```
DELETE FROM trips
WHERE id = 1;
```

**Натиҷаи интизоршаванда:** Рейси санҷишӣ аз рӯйхат хориҷ мешавад. Агар ба рейс чиптаҳо вобаста бошанд ва калиди хориҷӣ нест карданро манъ кунад, система бояд паёми фаҳмо нишон диҳад.

Хулосаи санҷиши CRUD

| Амалиёт | Амали иҷрошуда             | Натиҷаи интизоршаванда                         |
| ------- | -------------------------- | ---------------------------------------------- |
| Create  | Иловаи рейси нав           | Рейс сабт шуд                                  |
| Read    | Намоиши рейсҳо             | Рӯйхат нишон дода шуд                          |
| Update  | Тағйири нарх               | Маълумот нав шуд                               |
| Delete  | Нест кардани рейси санҷишӣ | Рейс нест шуд ё сабаби манъкунӣ нишон дода шуд |

## **3.3. Санҷиши ҷустуҷӯ ва филтркунӣ**

**Мақсад:** Санҷидани имконияти зуд пайдо кардани рейсҳои зарурӣ бо истифодаи ҷустуҷӯи матнӣ ва филтрҳо.

Дар системаи фурӯши чиптаҳои қатора шумораи рейсҳо метавонад зиёд бошад. Аз ин рӯ, ҷустуҷӯ ва филтркунӣ барои пайдо кардани рейси мувофиқ аҳамияти калон доранд.

Дар лоиҳа ҷустуҷӯ ва филтрҳо метавонанд аз рӯи параметрҳои зерин кор кунанд:

1. Рақами қатор.
2. Ҳолати рейс.
3. Санаи рафтан.

**Тартиби иҷро:**

1. Саҳифаи рейсҳоро мекушоем.
2. Дар майдони ҷустуҷӯ рақами қатораро ворид мекунем, масалан, `001`.
3. Тугмаи «Ҷустуҷӯ»-ро пахш мекунем.
4. Танҳо рейсҳои мувофиқ ба шарти ҷустуҷӯ бояд намоиш дода шаванд.
5. Баъдан филтри ҳолати рейсро интихоб мекунем, масалан, `scheduled`.
6. Санаи рафтанро муайян мекунем.
7. Тугмаи ҷустуҷӯро пахш карда, натиҷаҳоро месанҷем.

Мисоли дархости SQL:

```
SELECT *
FROM trips
WHERE train_id = :train_id
  AND status = :status
  AND DATE(departure_time) = :departure_date;
```

Дар барнома барои пешгирӣ намудани SQL Injection бояд параметрҳо тавассути Prepared Statements интиқол дода шаванд.

**Натиҷаи интизоршаванда:**

- Ҷустуҷӯ танҳо рейсҳои мувофиқро нишон медиҳад.
- Филтри ҳолат рейсҳоро аз рӯи статус ҷудо мекунад.
- Филтри сана рейсҳои рӯзи интихобшударо нишон медиҳад.
- Ҳангоми набудани натиҷа паёми «Рейсҳо ёфт нашуданд» намоиш дода мешавад.
- Ҳангоми тоза кардани филтрҳо рӯйхати умумии рейсҳо барқарор мешавад.

## **3.4. Санҷиши саҳифабандӣ (Pagination)**

**Мақсад:** Санҷидани тақсимоти рӯйхати рейсҳо ба якчанд саҳифа.

Саҳифабандӣ имкон медиҳад, ки ҳангоми зиёд будани маълумот ҳамаи сабтҳо якбора бор карда нашаванд. Ин усул суръати кори веб-барномаро беҳтар намуда, истифодаи захираҳои серверро кам мекунад.

Дар лоиҳа барои саҳифабандӣ параметрҳои зерин истифода мешаванд:

- `page` — рақами саҳифаи ҷорӣ.
- `limit` — шумораи сабтҳо дар як саҳифа.
- `offset` — шумораи сабтҳое, ки пеш аз натиҷаҳо гузаронида мешаванд.

Масалан, агар шумораи сабтҳо дар як саҳифа 5 бошад:

| Саҳифа | Рақами сабтҳо |
| ------ | ------------- |
| 1      | 1–5           |
| 2      | 6–10          |
| 3      | 11–15         |

Формулаи ҳисоб кардани OFFSET:

\\[ OFFSET=(page-1)\times limit \\]

Мисол:

```
$page = max(1, (int)($_GET['page'] ?? 1));

$limit = 5;

$offset = ($page - 1) * $limit;
```

Дархости SQL:

```
SELECT *
FROM trips
ORDER BY departure_time ASC
LIMIT :limit OFFSET :offset;
```

Ҳангоми истифодаи PDO параметрҳои `LIMIT` ва `OFFSET` бояд ҳамчун ададҳои бутун пайваст карда шаванд:

```
$stmt->bindValue(':limit', $limit, PDO::PARAM_INT);
$stmt->bindValue(':offset', $offset, PDO::PARAM_INT);
```

**Тартиби иҷро:**

1. Ба саҳифаи рейсҳо мегузарем.
2. Шумораи сабтҳоро дар як саҳифа муайян мекунем.
3. Агар маълумот аз шумораи интихобшуда зиёд бошад, тугмаҳои рақамҳои саҳифа пайдо мешаванд.
4. Тугмаи «Саҳифаи навбатӣ»-ро пахш мекунем.
5. Маълумоти саҳифаи дуюмро месанҷем.
6. Бозгашт ба саҳифаи якумро иҷро мекунем.
7. Ҷустуҷӯ ё филтрро фаъол намуда, ба саҳифаи дигар мегузарем.
8. Месанҷем, ки параметрҳои ҷустуҷӯ ва филтрҳо дар пайванди саҳифабандӣ нигоҳ дошта шудаанд.

**Натиҷаи интизоршаванда:**

- Дар ҳар саҳифа шумораи муайяни сабтҳо нишон дода мешавад.
- Сабтҳо такрор ё гум намешаванд.
- Ҳангоми гузариш ба саҳифаи дигар филтрҳои интихобшуда нигоҳ дошта мешаванд.
- Гузариш ба саҳифаи нодуруст ё манфӣ иҷозат дода намешавад.

## **3.5. Санҷиши JOIN ва GROUP BY**

**Мақсад:** Санҷидани дурустии гирифтани маълумот аз якчанд ҷадвали ба ҳам алоқаманд ва сохтани ҳисоботи ҷамъбастӣ.

Дар пойгоҳи додаҳои лоиҳа маълумот дар ҷадвалҳои алоҳида нигоҳ дошта мешавад. Масалан, маълумоти қаторҳо дар `trains`, маълумоти хатсайрҳо дар `routes` ва маълумоти сафарҳо дар `trips` нигоҳ дошта мешавад.

Барои гирифтани маълумоти пурра JOIN истифода мешавад.

### **3.5.1. Санҷиши JOIN**

JOIN имкон медиҳад, ки маълумоти якчанд ҷадвали вобаста тавассути калидҳои хориҷӣ якҷоя карда шавад.

Дар лоиҳаи мо:

- `trips.train_id` ба `trains.id` пайваст мешавад.
- `trips.route_id` ба `routes.id` пайваст мешавад.

Намунаи дархости SQL:

```
SELECT
    trips.id,
    trains.train_number,
    trains.train_name,
    routes.name AS route_name,
    trips.departure_time,
    trips.arrival_time,
    trips.base_price,
    trips.status
FROM trips
INNER JOIN trains
    ON trips.train_id = trains.id
INNER JOIN routes
    ON trips.route_id = routes.id
ORDER BY trips.departure_time ASC;
```

**Тартиби иҷро:**

1. Саҳифаи рӯйхати рейсҳоро мекушоем.
2. Маълумоти намоишдодашударо месанҷем.
3. Рақами қатор ва номи он бояд аз ҷадвали `trains` гирифта шаванд.
4. Номи хатсайр бояд аз ҷадвали `routes` гирифта шавад.
5. Вақти рафтан, вақти расидан, нарх ва ҳолати рейс аз ҷадвали `trips` гирифта мешаванд.

**Натиҷаи интизоршаванда:** Дар рӯйхати рейсҳо маълумоти пурра намоиш дода мешавад. Ба ҷойи нишон додани танҳо ID-и қатор ва хатсайр, номҳои мувофиқ нишон дода мешаванд.

### **3.5.2. Санҷиши GROUP BY**

GROUP BY барои гурӯҳбандӣ ва ҳисоб кардани маълумоти ҷамъбастӣ истифода мешавад.

Дар лоиҳаи мо метавонем шумораи рейсҳоро аз рӯи ҳар як хатсайр ҳисоб кунем.

Мисоли дархости SQL:

```
SELECT
    routes.name AS route_name,
    COUNT(trips.id) AS total_trips,
    AVG(trips.base_price) AS average_price,
    MIN(trips.base_price) AS minimum_price,
    MAX(trips.base_price) AS maximum_price
FROM routes
LEFT JOIN trips
    ON routes.id = trips.route_id
GROUP BY routes.id, routes.name
ORDER BY total_trips DESC;
```

Дар ин дархост:

- `COUNT()` — шумораи рейсҳоро ҳисоб мекунад.
- `AVG()` — нархи миёнаи чиптаҳоро муайян мекунад.
- `MIN()` — нархи пасттаринро меёбад.
- `MAX()` — нархи баландтаринро меёбад.
- `GROUP BY` — рейсҳоро аз рӯи хатсайр гурӯҳбандӣ мекунад.
- `LEFT JOIN` — хатсайрҳоеро низ нигоҳ медорад, ки ҳоло рейс надоранд.

**Тартиби иҷро:**

1. Қисми ҳисоботи ҷамъбастиро мекушоем.
2. Маълумоти хатсайрҳоро аз рӯи шумораи рейсҳо месанҷем.
3. Шумораи умумии рейсҳои ҳар як хатсайрро муқоиса мекунем.
4. Нархи миёна, пасттарин ва баландтаринро месанҷем.
5. Боварӣ ҳосил мекунем, ки хатсайри бе рейс низ дар ҳисобот бо шумораи сифр нишон дода мешавад.

**Натиҷаи интизоршаванда:** Ҳисоботи ҷамъбастӣ дуруст сохта шуда, шумораи рейсҳо ва нишондиҳандаҳои нарх барои ҳар хатсайр намоиш дода мешаванд.

## **3.6. Санҷиши амният ва дурустии маълумоти воридшаванда**

**Мақсад:** Санҷидани муҳофизати веб-барнома аз дархостҳои ғайриқонунӣ, маълумоти нодуруст ва хатогиҳои пойгоҳи додаҳо.

Дар веб-барнома ҳамаи маълумоте, ки аз тарафи корбар ворид карда мешавад, бояд пеш аз сабт дар пойгоҳи додаҳо санҷида шавад.

### **3.6.1. Санҷиши CSRF Token**

CSRF (Cross-Site Request Forgery) — ҳамлаест, ки дар он шахси бегона кӯшиш мекунад аз номи корбари воридшуда дархости ғайриқонунӣ фиристад.

Барои пешгирии ин ҳамла дар форма CSRF token истифода мешавад.

Намунаи илова кардани token ба форма:

```
<input
    type="hidden"
    name="csrf_token"
    value="<?= htmlspecialchars($_SESSION['csrf_token']) ?>"
>
```

**Тартиби санҷиш:**

1. Формаи илова ё таҳрири рейсро мекушоем.
2. Дархости муқаррарии POST-ро мефиристем.
3. Боварӣ ҳосил мекунем, ки амалиёт иҷро мешавад.
4. Баъдан CSRF token-ро аз дархост хориҷ мекунем.
5. Дархостро бе token мефиристем.
6. Натиҷаи ҷавоби серверро месанҷем.

**Натиҷаи интизоршаванда:** Дархости POST бе CSRF token рад карда мешавад ва маълумот ба пойгоҳи додаҳо ворид намегардад.

### **3.6.2. Санҷиши майдонҳои ҳатмӣ**

Ҳамаи майдонҳои ҳатмии форма бояд санҷида шаванд.

Масалан:

| Майдон        | Санҷиши зарурӣ                           |
| ------------- | ---------------------------------------- |
| Қатор         | Интихоби қаторе, ки дар база мавҷуд аст  |
| Хатсайр       | Интихоби хатсайри мавҷуда                |
| Вақти рафтан  | Майдон холӣ набошад ва сана дуруст бошад |
| Вақти расидан | Аз вақти рафтан дертар бошад             |
| Ҳолати рейс   | Танҳо қиматҳои иҷозатдодашуда            |
| Нархи чипта   | Адади дуруст ва ғайриманфӣ бошад         |

**Тартиби санҷиш:**

1. Формаи илова кардани рейсро мекушоем.
2. Ҳамаи майдонҳоро холӣ гузошта, тугмаи захираро пахш мекунем.
3. Паёмҳои хатогиро месанҷем.
4. Баъдан танҳо баъзе майдонҳоро пур мекунем.
5. Боварӣ ҳосил мекунем, ки система маълумоти нопурраро қабул намекунад.

**Натиҷаи интизоршаванда:** Система майдонҳои ҳатмиро муайян карда, паёмҳои мувофиқи хатогиро нишон медиҳад. Маълумоти воридшудаи корбар ҳангоми хатои санҷишӣ дар форма нигоҳ дошта мешавад.

### **3.6.3. Санҷиши нархи манфӣ**

**Тартиби санҷиш:**

1. Формаи илова кардани рейсро мекушоем.
2. Дар майдони нарх қимати `-100`-ро ворид мекунем.
3. Формаи худро мефиристем.
4. Ҷавоби серверро месанҷем.

**Натиҷаи интизоршаванда:** Система нархи манфиро рад мекунад ва паёми хатогии «Нархи чипта набояд манфӣ бошад»-ро нишон медиҳад.

### **3.6.4. Санҷиши сана ва вақти нодуруст**

**Тартиби санҷиш:**

1. Формаи илова кардани рейсро мекушоем.
2. Вақти рафтанро, масалан, `2026-12-15 14:00` мегузорем.
3. Вақти расиданро `2026-12-15 08:00` мегузорем.
4. Формаи худро мефиристем.
5. Ҷавоби серверро месанҷем.

**Натиҷаи интизоршаванда:** Система рейсеро, ки вақти расиданаш аз вақти рафтан пештар аст, қабул намекунад.

### **3.6.5. Санҷиши маҳдудияти калиди хориҷӣ (Foreign Key)**

Foreign Key робитаи байни ҷадвалҳоро нигоҳ медорад ва аз нест шудани маълумоти вобаста пешгирӣ мекунад.

Масалан, дар лоиҳаи мо ҷадвали `tickets` ба ҷадвали `trips` вобастагӣ дорад.

**Тартиби санҷиш:**

1. Дар пойгоҳи додаҳо рейсеро интихоб мекунем, ки барои он чипта мавҷуд аст.
2. Кӯшиш мекунем ин рейсро нест кунем.
3. Системаи идоракунии пойгоҳи додаҳо маҳдудияти калиди хориҷиро месанҷад.
4. Агар несткунӣ манъ бошад, сервер хатои PDO-ро қабул мекунад.
5. Controller хатогиро коркард намуда, паёми фаҳмо нишон медиҳад.

**Натиҷаи интизоршаванда:** Рейс бе иҷозат ва нест кардани маълумоти вобаста нест намешавад. Ба ҷойи хатои умумии HTTP 500 паёми фаҳмо, масалан, «Ин рейс чиптаҳои вобаста дорад ва нест карда намешавад», нишон дода мешавад.

### **3.6.6. Санҷиши Prepared Statements ва пешгирии SQL Injection**

SQL Injection яке аз хатарҳои асосии барномаҳои вебӣ мебошад. Ин ҳамла ҳангоми ворид кардани коди зараровари SQL ба майдонҳои ҷустуҷӯ ё форма ба вуҷуд омада метавонад.

Дар лоиҳа барои пешгирии ин хатар Prepared Statements истифода мешаванд.

**Тартиби санҷиш:**

1. Майдони ҷустуҷӯи рейсҳоро мекушоем.
2. Ба ҷойи рақами қатор матни санҷишии зеринро ворид мекунем:

```
' OR '1'='1
```

3. Ҷустуҷӯро иҷро мекунем.
4. Натиҷаи намоишдодашударо месанҷем.

**Натиҷаи интизоршаванда:** Матни воридшуда ҳамчун маълумоти одӣ қабул мешавад, на ҳамчун фармони SQL. Система набояд ҳамаи рейсҳоро танҳо аз сабаби ворид кардани ин матн намоиш диҳад.

### **3.6.7. Санҷиши HTTP 422 ва нигоҳ доштани маълумоти форма**

HTTP 422 (Unprocessable Content) рамзи ҷавобест, ки ҳангоми нодуруст будани маълумоти воридшуда истифода мешавад.

**Тартиби санҷиш:**

1. Формаи илова кардани рейсро мекушоем.
2. Дар майдони нарх қимати нодуруст ворид мекунем.
3. Формаи худро мефиристем.
4. Рамзи HTTP-и ҷавоби серверро месанҷем.
5. Бозгашти форма ва нигоҳ доштани маълумоти дуруст воридшударо месанҷем.

**Натиҷаи интизоршаванда:**

- Сервер барои маълумоти нодуруст HTTP 422 бармегардонад.
- Паёми хатогӣ нишон дода мешавад.
- Маълумоти дурусти воридшуда дар форма нигоҳ дошта мешавад.
- То ислоҳ шудани хатогиҳо маълумот ба база сабт намешавад.

# **3.7. Ҷадвали умумии натиҷаҳои санҷишҳо**

Дар ин ҷадвал натиҷаҳои санҷишҳо сабт карда мешаванд. Дар сутуни «Натиҷаи воқеӣ» танҳо натиҷаи амалиёти воқеан иҷрошударо навис.

# **4. Хулоса**

Дар натиҷаи иҷрои кори лаборатории №13 мавзӯи пайвастшавӣ ва коркарди маълумот дар пойгоҳи додаҳо бо истифодаи забони барномасозии PHP ва технологияи PDO омӯхта шуд.

Дар раванди иҷрои лабораторӣ барои лоиҳаи «Системаи фурӯши онлайнии чиптаҳои қатораҳои байнишаҳрӣ» сохтори кор бо пойгоҳи додаҳо такмил дода шуда, принсипи Repository истифода гардид. Ин принсип имкон медиҳад, ки қисми коркарди дархостҳои SQL аз Controller ва қисми намоиши маълумот ҷудо нигоҳ дошта шавад. Дар натиҷа, сохтори барнома мураттаб, фаҳмо ва барои васеъкунӣ қулай мегардад.

Барои объекти асосии лоиҳа — рейсҳои қатора (таблисаи `trips`) чор амалиёти асосии CRUD амалӣ карда шуданд:

1. **Create** — илова намудани рейси нав ба пойгоҳи додаҳо.
2. **Read** — гирифтани маълумот ва намоиши рӯйхати рейсҳо.
3. **Update** — таҳрир ва навсозии маълумоти рейсҳо.
4. **Delete** — нест намудани рейсҳои санҷишӣ бо риояи маҳдудиятҳои пойгоҳи додаҳо.

Ҳамчунин имкониятҳои ҷустуҷӯ ва филтркунӣ барои пайдо кардани рейсҳо аз рӯи рақами қатор, ҳолат ва санаи рафтан пешбинӣ гардиданд. Барои коркарди миқдори зиёди маълумот саҳифабандӣ (Pagination) истифода шуда, тақсимоти маълумот ба саҳифаҳо ва нигоҳ доштани параметрҳои ҷустуҷӯ санҷида мешавад.

Дар қисми кор бо ҷадвалҳои алоқаманд фармони `JOIN` барои гирифтани маълумоти қаторҳо ва хатсайрҳо аз ҷадвалҳои вобаста истифода мешавад. Фармони `GROUP BY` бошад, барои гурӯҳбандии рейсҳо аз рӯи хатсайр ва ҳисоб кардани нишондиҳандаҳои ҷамъбастӣ, аз ҷумла шумораи рейсҳо ва нархи миёнаи чиптаҳо, пешбинӣ шудааст.

Дар қисми амният ва дурустии маълумот санҷиши майдонҳои форма, маҳдуд кардани нархи манфӣ, санҷиши сана ва вақт, истифодаи CSRF Token ва Prepared Statements баррасӣ гардиданд. Инчунин коркарди хатогиҳои пойгоҳи додаҳо ва маҳдудиятҳои Foreign Key барои пешгирӣ намудани нестшавии маълумоти вобаста муҳим мебошад.

Истифодаи HTTP 422 барои маълумоти нодуруст ва PRG (Post/Redirect/Get) пас аз амалиёти муваффақ имкон медиҳад, ки кор бо формаҳо дуруст ташкил карда шавад ва дархости POST такроран фиристода нашавад.

**Дар маҷмӯъ**, иҷрои ин лаборатория барои мустаҳкам намудани донишҳои назариявӣ ва амалӣ оид ба кор бо пойгоҳи додаҳо, ташкили сохтори бисёрқабатаи веб-барнома, коркарди маълумот ва таъмини амнияти он замина фароҳам меорад. Ин имкониятҳо барои фаъолияти дурусти системаи фурӯши онлайнии чиптаҳои қатораҳои байнишаҳрӣ аҳамияти муҳим доранд.
