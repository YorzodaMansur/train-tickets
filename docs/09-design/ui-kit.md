# **UI-kit: Роҳи Оҳани Тоҷикистон — Чиптаҳои байнишаҳрӣ 2026–2027**

**Figma:** [Истиноди файли «Train Ticket System — Design»-ро гузоред. Дастрасӣ: «https://www.figma.com/design/gVqhbgIuPXND9h5YC4GlbG/Untitled?node-id=6-655&p=f&t=Mw0TtcfOVAUpNoWp-0».]

**Прототип:** [Истиноди Present-ро гузоред. Ҷараён: «Харидории чипта».]

**Мавзӯъ: Торик (Dark Theme).**

Рамзҳои рангии HEX аз скриншотҳои сомона гирифта шудаанд. Онҳоро бо асбоби қатрачакон (I) дар Figma санҷед.

## **Ранги бренд ва Bootstrap (рӯзи 10)**

Ранги бренди сомона — градиенти `#06B6D4 → #2563EB` ва ранги иловагӣ `#22D3EE` мебошад. Ин рангҳо аз ранги стандартии кабуди Bootstrap фарқ мекунанд.

Дар рӯзи 10 параметрҳои зерин тағйир дода мешаванд:

- `--bs-primary: #0E7490` — ранги cyan-и торикшуда, ки бо матни сафед контрасти 5.36:1 дорад.
- `--bs-primary-rgb: 14, 116, 144`
- `--bs-body-bg: #0A0F1E` — ранги заминаи саҳифа.
- `--bs-body-color: #FFFFFF` — ранги матни асосӣ.
- `--bs-border-color: #263043` — ранги сарҳадҳо.
- `--bs-link-color: #22D3EE` — ранги пайвандҳо.

Барои фаъол кардани мавзӯи торик, инчунин `data-bs-theme="dark"` дар элементи `html` гузошта мешавад.

## **Сетка (Grid)**

- **Desktop 1440:** 12 сутун × 88 px, фосилаи байни сутунҳо (gutter) — 24 px, паҳнои қисми мундариҷа — 1320 px (`.container`).
- **Mobile 390:** 4 сутун бо паҳнои Stretch, ҳошияи паҳлуӣ — 16 px, фосилаи байни сутунҳо — 16 px.

Қадамҳои фосилагузорӣ: 4 / 8 / 16 / 24 / 32 px.

Ҳуруфи истифодашаванда — **Noto Sans** (бо дастгирии пурраи алифбои кириллӣ ва ҳарфҳои тоҷикӣ: ӣ, ӯ, қ, ғ, ҳ, ҷ).

## **Компонентҳо (Components)**

\- **Button (Тугма):** Primary / Secondary / Danger × Default / Hover / Disabled. Баландӣ — 52–56 px.\
Дар Bootstrap: `.btn`, `.btn-primary`, `.btn-outline-secondary`, `.btn-danger`.

\- **Input (Майдони воридкунӣ):** Default / Focus / Error / Disabled. Баландӣ — 52 px, шарҳи майдон дар болои он ҷойгир мешавад.\
Дар Bootstrap: `.form-control`, `.is-invalid`.

\- **TripCard (Корти қатора):** бо истифодаи Auto Layout сохта мешавад. Дар он рақами қатора, хатсайр, вақти ҳаракат, нарх ва тугмаи «Интихоби вагон ва ҷой» ҷойгир мешаванд.\
Дар Bootstrap: `.card` ва `.d-flex`.

\- **Navbar (Панели паймоиш):** барои корбари вориднашуда (Guest) ва корбари воридшуда (Auth).

\- **Chip (Нишона):** «Хатсайрҳои машҳур».

## **Масирҳо (Номҳои экранҳо)**

| Экран                   | Масир         |
| ----------------------- | ------------- |
| Саҳифаи асосӣ (ҷустуҷӯ) | `/`           |
| Бақайдгирӣ              | `/register`   |
| Воридшавӣ               | `/login`      |
| Ҷадвали қатораҳо        | `/trains`     |
| Чиптаҳои ман            | `/my-tickets` |

Масирҳоро бо суроғаҳои воқеии сомона (масалан, `index.php` ва дигар файлҳо) муқоиса карда, дар ҳолати зарурӣ ислоҳ кунед.

## **Ҷараёни кори корбар (User Flow)**

**1. US-01 — Харидории чипта:**

`/` → `/login` → `/trains` → [Интихоби вагон ва ҷой] → `/my-tickets`

Натиҷа: паёми «Чипта харида шуд».

**2. US-02 — Бақайдгирии корбар:**

`/` → `/register` → `/login` → `/my-tickets`

Натиҷа: саҳифаи «Чиптаҳои ман» бе маълумот (ҳолати холӣ).
