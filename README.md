## 1. Тавсифи лоиҳа

Лоиҳаи мазкур барои автоматикунонии фурӯши чиптаҳои роҳи оҳан байни шаҳрҳои Ҷумҳурии Тоҷикистон (Душанбе, Хуҷанд, Бохтар, Кӯлоб, Конибодом ва ғ.) пешбинӣ шудааст. Низом ба мусофирон имкон медиҳад, ки қатнавҳоро ҷустуҷӯ кунанд, нақшаи вагонро (купе, плацкарт) бинанд, ҷойи дилхоҳро дар харитаи интерактивӣ интихоб намоянд, онро ба муддати **15 дақиқа** банд кунанд, пардохт намоянд ва чиптаро дар шакли **PDF** бо рамзи QR чоп кунанд.

Барои кормандон нақшҳои махсус мавҷуданд:
- **Кассир:** метавонад дар касса чипта фурӯшад ва бо хоҳиши мусофир чиптаро баргардонад (refund).
- **Маъмур (Администратор):** истгоҳҳо, хатсайрҳо, қатнавҳо, вагонҳо, нархҳоро идора мекунад ва ҳисоботи фурӯшро мебинад.

## 2. Хусусиятҳои асосӣ (Талаботи техникӣ)

1. **Ҷустуҷӯи қатнавҳо:** Ҷустуҷӯ аз рӯи истгоҳи оғоз, анҷом ва санаи сафар.
2. **Нақшаи интерактивии вагон (Seat Map):** 
   - Ҷойҳои холӣ бо ранги **сабз**;
   - Ҷойҳои фурӯхташуда бо ранги **сурх**;
   - Ҷойҳои муваққатан бандбуда бо ранги **зард**;
   - Ҷойи интихобкардаи корбар бо ранги **кабуд**.
3. **Банди муваққатӣ ба муддати 15 дақиқа:**
   - Баробари оғози расмиёт, ҷой барои 15 дақиқа мунҷамид (lock) мешавад;
   - Дар экран таймери ҳисоби баръакс (15:00 → 00:00) кор мекунад;
   - Агар дар давоми 15 дақиқа пардохт нашавад, низом ба таври худкор ҷойро озод мекунад.
4. **Тавлиди чиптаи электронии PDF бо QR-код:** Чиптаи стандартӣ бо маълумоти пурраи сафар ва имкони чопи мустақим.
5. **Модули кассир:** Фурӯши фаврӣ ва баргардонидани чипта бо ҳисобкунии ҷуброн.
6. **Панели маъмур ва ҳисобот:** Нишондиҳандаҳои фурӯш, даромад, фоизи пуршавии вагонҳо.

## 3. Стек ва талаботи муҳит

- **PHP:** 8.2+ (бо васеъшавиҳои PDO, pdo_mysql, pdo_sqlite, mbstring, openssl)
- **МБДД (СУБД):** MariaDB 10.4+ / MySQL 8.0+ (ҳамчунин режими худкори SQLite барои санҷиши фаврӣ фаъол аст)
- **Фронтенд:** Bootstrap 5.3, Bootstrap Icons, Vanilla JavaScript, HTML5/CSS3
- **Меъморӣ:** Мукаммали MVC (Model-View-Controller) бидуни фреймворкҳои вазнини беруна

## 5. Роҳнамои оғоз ва насб

### Усули 1. Бо веб-сервери дарунсохти PHP (Тавсияшаванда барои санҷиш)
1. Терминалро дар ҷузвдони решавии лоиҳа боз кунед:
   ```powershell
   cd railway-tickets
   ```
2. Сервери маҳаллиро оғоз намоед:
   ```powershell
   php -S localhost:8000 -t public
   ```
3. Дар браузер суроғаи зеринро ворид кунед:
   ```text
   http://localhost:8000
   ```
   *(Эзоҳ: Пойгоҳи додаҳо ҳангоми оғози аввалин ба таври худкор бо маълумоти пурраи намунавӣ омода мегардад).*

### Усули 2. Дар муҳити XAMPP
1. Ҷузвдонро ба `C:\xampp\htdocs\railway-tickets` нусхабардорӣ кунед.
2. Дар phpMyAdmin пойгоҳи додаҳои `railway_tickets`-ро сохта, файли `database/schema.sql` ва `database/seed.sql`-ро импорт намоед.
3. Ба суроғаи `http://localhost/railway-tickets/public/` ворид шавед.
