# train-tickets — Веблоиҳаи фурӯши чиптаҳо барои қатораҳои байнишаҳрӣ

Лоиҳаи семестрӣ аз фанни «Технологияҳо ва забонҳои барномасозии интернетӣ».

## Тавсиф
Системаи иттилоотӣ барои ҷустуҷӯ, брон ва харидани чиптаҳои қатораҳои байнишаҳрӣ.
Нақшҳо: **Мусофир**, **Кассир**, **Администратор**.

## Технологияҳо
PHP 8.2+, MySQL 8 / MariaDB 10.6+, PDO, Bootstrap 5, JavaScript-и тоза, Composer (PSR-4), PHPUnit.

## Сохтори лоиҳа
- `docs/` — ҳуҷҷатҳои тарроҳӣ (лаб. 1–9)
- `database/` — schema.sql, seed.sql, queries.sql (аз лаб. 7)
- `public/`, `src/`, `views/`, `config/`, `tests/` — коди барнома (аз лаб. 10)

## Нусхабардорӣ ва оғоз (баъдтар пур карда мешавад)
```bash
git clone <суроғаи репозиторий> train-tickets
```
